GSC 驱动导致卡顿的修复方法

针对 Graphics System Controller Firmware Interface（GSC）驱动导致的音频爆音、声音断续和画面冻结问题。已在 LAPAC71H / LAPAC71G，以及 Arc A730M / Arc A550M 上验证。

LAPAC71HLAPAC71GArc A730MArc A550M
重要：以下操作涉及显卡驱动的卸载、回滚以及阻止 Windows 自动更新。操作前请做好数据备份，并确保你能够进入 Windows 安全模式和恢复系统。
快速方法（推荐）：可以跳过步骤 1、步骤 3 和步骤 7 （下载 DDU、使用 DDU 清理以及阻止驱动更新）。只需执行步骤 2、4、5、6 —— 正常安装旧版驱动， 然后只回滚 GSC 设备。只有当快速方法无效时，才使用完整方法（含 DDU 和驱动更新阻止）。

注意事项

以下步骤不是强制要求，但建议在操作前完成：

  • 备份：保存重要数据。
  • BitLocker：如果已启用，请提前找到恢复密钥。进入安全模式时可能需要。
  • 网络：操作期间断开互联网（Wi-Fi / Ethernet），避免 Windows 自动更新驱动。
  • 密码：确认记得账户密码，而不是 PIN；Windows 11 安全模式可能要求输入密码。

步骤 1：下载 DDU（Display Driver Uninstaller）

快速方法：跳过此步骤。

  1. 打开官方地址：Wagnardsoft。
  2. 找到 Display Driver Uninstaller（DDU），下载 Portable / Self-Extracting 版本。
  3. 将压缩包解压到方便访问的文件夹。

步骤 2：下载 31.0.101.5590 驱动

  1. 打开下载页面：COMSS。
  2. 下载 Intel-Graphics-Driver-31.0.101.5590.exe（约 866 MB）。
  3. 暂时不要安装，先删除旧驱动。

Intel 已不再在官网直接提供该旧版本驱动。

步骤 3：使用 DDU 删除旧驱动

快速方法：跳过此步骤。

  1. 断开互联网。
  2. 运行 DDU.exe。
  3. 选择：
    • Device type：GPU
    • Select device：Intel
  4. 点击 Clean and restart。
  5. 电脑会重启进入安全模式并清理 Intel 驱动。
  6. 安装新驱动之前不要重新连接互联网。

步骤 4：安装 31.0.101.5590 驱动

  1. 运行刚才下载的安装程序。
  2. 按照安装程序提示操作。
  3. 如果出现选项，选择 Clean Install。
  4. 重启电脑。
✓ 检查：打开“设备管理器 → 系统设备 → Intel(R) Graphics System Controller Firmware Interface”，版本应为 31.0.101.5590。

步骤 5：更新显卡驱动到最新版本

  1. 重新连接互联网。
  2. 安装最新的 Intel Arc / Iris Xe 驱动：Intel Arc Graphics Windows Driver。
  3. 重启电脑。

步骤 6：回滚 GSC 驱动

  1. 打开设备管理器（Win + X → 设备管理器）。
  2. 展开系统设备。
  3. 找到 Intel(R) Graphics System Controller Firmware Interface。
  4. 右键 → 更新驱动程序。
  5. 选择浏览我的电脑以查找驱动程序。
  6. 点击让我从计算机上的可用驱动程序列表中选取。
  7. 选择版本 31.0.101.5590。
  8. 点击下一步并等待安装完成。
  9. 可选：重启电脑。
✓ 检查：打开“事件查看器 → Windows 日志 → 系统”，按来源 GSCx64 筛选。正常情况下不应再出现相关事件。

步骤 7：阻止 Windows 更新 GSC 驱动

快速方法：跳过此步骤。

方法 1：组策略（推荐）

  1. 按 Win + R，输入 gpedit.msc，回车。
  2. 进入：计算机配置 → 管理模板 → Windows 组件 → Windows Update → 管理从 Windows Update 提供的更新。
  3. 找到不包括 Windows 更新中的驱动程序。
  4. 设置为已启用 → 确定。
  5. 重启电脑。

方法 2：系统设置

  1. 按 Win + R，输入 sysdm.cpl，回车。
  2. 进入硬件 → 设备安装设置。
  3. 选择否（你的设备可能无法按预期工作）。
  4. 保存设置。

如何验证修复是否生效

  1. 打开事件查看器 → Windows 日志 → 系统。
  2. 按来源 GSCx64 筛选。
  3. 确认没有新事件，或者只有回滚之前产生的事件。
  4. 运行游戏或高负载应用 10–15 分钟。
  5. 如果没有音频爆音、声音断续和画面冻结，则说明该问题已得到解决。

FAQ

驱动 31.0.101.5590 没有出现在列表中？
  • 确认下载的是正确版本。
  • 尝试“更新驱动程序 → 浏览我的电脑 → 从列表中选取 → 从磁盘安装”，然后指定驱动程序文件夹。
回滚之后卡顿仍然存在？
  • 问题可能由其他因素导致，例如温度、电源或 RAM。
  • 可以尝试在设备管理器中临时禁用 GSC 设备。
禁用 GSC 安全吗？

GSC 负责 GPU 固件更新以及部分安全相关任务。禁用后可能消除卡顿，但同时会阻止固件更新。

为什么 Windows 11 24H2 会更新 GSC？

原文说明 Windows 11 24H2 会强制更新包括 GSC 在内的驱动，组策略可以阻止这一行为。

说明

大型 Windows 更新之后，GSC 驱动可能再次被替换。此时重复步骤 6进行回滚。Windows 会在磁盘上保留旧版驱动文件。

GSC Driver Stutter Fix

This guide addresses audio crackling and image freezes caused by the Graphics System Controller Firmware Interface (GSC) driver. Verified on LAPAC71H/LAPAC71G with Arc A730M and Arc A550M.

LAPAC71HLAPAC71GArc A730MArc A550M
Important: These steps involve removing, rolling back, and blocking Windows driver updates. Back up important data before starting.
Quick method (recommended): you can skip Step 1, Step 3, and Step 7 (DDU download, DDU cleanup, and blocking driver updates). Just do Steps 2, 4, 5, 6 — install the old driver normally, then roll back only the GSC device. Use the full method (with DDU and blocking) only if the quick method doesn't work.

Warning

The following steps are not mandatory, but are recommended for safety:

  • Backup: Save your important data before you start.
  • BitLocker: If enabled, find your recovery key. You may need it when booting into Safe Mode.
  • Internet: Disconnect from the internet (Wi-Fi/Ethernet) during the process to prevent Windows from auto-updating drivers.
  • Password: Make sure you remember your account password (not the PIN), as Windows 11 Safe Mode may ask for it.

Step 1: Download DDU (Display Driver Uninstaller)

Quick method: skip this step.

  1. Go to the official website: Wagnardsoft.
  2. Find Display Driver Uninstaller (DDU) and download the Portable / Self-Extracting version.
  3. Extract the archive to a convenient folder.

Step 2: Download driver 31.0.101.5590

  1. Open the download page: COMSS.
  2. Download Intel-Graphics-Driver-31.0.101.5590.exe (~866 MB).
  3. Do not install it yet — first remove the old drivers.

Intel no longer hosts old drivers on its site, unfortunately.

Step 3: Remove old drivers with DDU

Quick method: skip this step.

  1. Disconnect from the internet.
  2. Run DDU.exe.
  3. Select:
    • Device type: GPU
    • Select device: Intel
  4. Click Clean and restart.
  5. The PC will reboot into Safe Mode and clean Intel drivers.
  6. Do not reconnect to the internet until you install the new driver.

Step 4: Install driver 31.0.101.5590

  1. Run the downloaded installer.
  2. Follow the instructions.
  3. Select Clean Install if prompted.
  4. Reboot.
✓ Check: Device Manager → "System devices" → "Intel(R) Graphics System Controller Firmware Interface". Version should be 31.0.101.5590.

Step 5: Update GPU drivers to the latest version

  1. Reconnect to the internet.
  2. Install the latest Intel Arc/Iris Xe driver: Intel Arc Graphics Windows Driver.
  3. Reboot.

Step 6: Roll back the GSC driver

  1. Open Device Manager (Win + X → Device Manager).
  2. Expand "System devices".
  3. Find "Intel(R) Graphics System Controller Firmware Interface".
  4. Right-click → "Update driver".
  5. Select "Browse my computer for drivers".
  6. Click "Let me pick from a list of available drivers".
  7. Select version 31.0.101.5590.
  8. Click "Next" and wait.
  9. Reboot (optional).
✓ Check: Event Viewer → Windows Logs → System. Filter by source GSCx64. No events should be present.

Step 7: Block Windows from updating the GSC driver

Quick method: skip this step.

Method 1: Group Policy (recommended)

  1. Press Win + R, type gpedit.msc, Enter.
  2. Go to: Computer Configuration → Administrative Templates → Windows Components → Windows Update → Manage updates offered from Windows Update.
  3. Find "Do not include drivers with Windows Updates".
  4. Set to "Enabled" → OK.
  5. Reboot.

Method 2: System Settings

  1. Press Win + R, type sysdm.cpl, Enter.
  2. "Hardware" tab → "Device Installation Settings".
  3. Select "No (your device might not work as expected)".
  4. Save.

How to verify the fix worked

  1. Open Event Viewer → Windows Logs → System.
  2. Filter by source GSCx64.
  3. No events (or only events from before the rollback).
  4. Run a game / heavy app for 10–15 minutes.
  5. No audio crackling, no image freezes → fixed.

FAQ

Driver 31.0.101.5590 doesn't appear in the list?
  • Make sure you downloaded the correct version.
  • Try: "Update driver" → "Browse my computer" → "Let me pick from a list" → "Have Disk" → point to the driver folder.
Stutter doesn't go away after rollback?
  • The issue might be caused by other factors (thermals, power, RAM).
  • Try disabling the GSC device in Device Manager (temporary workaround).
Is it safe to disable GSC?

GSC handles GPU firmware updates and some security tasks. Disabling removes stutter but blocks firmware updates.

Why does Windows 11 24H2 update GSC?

Windows 11 24H2 force-updates all drivers, including GSC. Group Policy blocks this.

Note

After a major Windows update, the GSC driver may be replaced again. Repeat Step 6 to roll it back. Windows keeps old driver files on disk.

GSC ドライバーによるスタッターの修正

Graphics System Controller Firmware Interface（GSC）ドライバーが原因で発生する音声のノイズ・途切れや、画面のフリーズに対処します。LAPAC71H / LAPAC71G、Arc A730M / Arc A550M で確認されています。

LAPAC71HLAPAC71GArc A730MArc A550M
重要：この手順では、GPU ドライバーの削除、ロールバック、および Windows による自動更新の停止を行います。開始前に重要なデータをバックアップしてください。
クイック方法（推奨）：手順 1、手順 3、手順 7（DDU のダウンロード、DDU による 削除、ドライバー更新のブロック）を省略できます。手順 2、4、5、6 のみ実行してください —— 古いドライバーを通常どおりインストールし、その後 GSC デバイスのみをロールバックします。 クイック方法で解決しない場合のみ、完全な方法（DDU とブロックを含む）を使用してください。

注意事項

以下の手順は必須ではありませんが、安全のため推奨します。

  • バックアップ：重要なデータを保存してください。
  • BitLocker：有効になっている場合は、回復キーを確認してください。セーフモードで起動するときに必要になる場合があります。
  • インターネット：作業中は Wi-Fi / Ethernet を切断し、Windows によるドライバーの自動更新を防いでください。
  • パスワード：アカウントのパスワード（PIN ではないもの）を確認してください。Windows 11 のセーフモードではパスワードを要求される場合があります。

手順 1：DDU（Display Driver Uninstaller）をダウンロード

クイック方法：この手順を省略します。

  1. 公式サイト Wagnardsoft を開きます。
  2. Display Driver Uninstaller（DDU） を探し、Portable / Self-Extracting 版をダウンロードします。
  3. アーカイブを任意のフォルダーに展開します。

手順 2：ドライバー 31.0.101.5590 をダウンロード

  1. ダウンロードページ COMSS を開きます。
  2. Intel-Graphics-Driver-31.0.101.5590.exe（約 866 MB）をダウンロードします。
  3. まだインストールしないでください。先に古いドライバーを削除します。

Intel は現在、古いドライバーを公式サイトで提供していません。

手順 3：DDU で古いドライバーを削除

クイック方法：この手順を省略します。

  1. インターネットを切断します。
  2. DDU.exe を実行します。
  3. 以下を選択します：
    • Device type：GPU
    • Select device：Intel
  4. Clean and restart をクリックします。
  5. PC がセーフモードで再起動し、Intel ドライバーを削除します。
  6. 新しいドライバーをインストールするまでインターネットに再接続しないでください。

手順 4：ドライバー 31.0.101.5590 をインストール

  1. ダウンロードしたインストーラーを実行します。
  2. 画面の指示に従います。
  3. 表示された場合は Clean Install を選択します。
  4. 再起動します。
✓ 確認：デバイス マネージャー →「システム デバイス」→「Intel(R) Graphics System Controller Firmware Interface」を確認します。バージョンは 31.0.101.5590 である必要があります。

手順 5：GPU ドライバーを最新バージョンに更新

  1. インターネットに再接続します。
  2. 最新の Intel Arc / Iris Xe ドライバーを Intel Arc Graphics Windows Driver からインストールします。
  3. 再起動します。

手順 6：GSC ドライバーをロールバック

  1. デバイス マネージャーを開きます（Win + X → デバイス マネージャー）。
  2. 「システム デバイス」を展開します。
  3. 「Intel(R) Graphics System Controller Firmware Interface」を探します。
  4. 右クリック → 「ドライバーの更新」。
  5. 「コンピューターを参照してドライバーを検索」を選択します。
  6. 「コンピューター上の利用可能なドライバーの一覧から選択」をクリックします。
  7. バージョン 31.0.101.5590 を選択します。
  8. 「次へ」をクリックして待ちます。
  9. 必要に応じて再起動します。
✓ 確認：イベント ビューアー → Windows ログ → システムで、ソースを GSCx64 に絞り込みます。新しいイベントが発生していないことを確認します。

手順 7：Windows による GSC ドライバーの更新をブロック

クイック方法：この手順を省略します。

方法 1：グループ ポリシー（推奨）

  1. Win + R を押し、gpedit.msc と入力して Enter。
  2. コンピューターの構成 → 管理用テンプレート → Windows コンポーネント → Windows Update → Windows Update から提供される更新プログラムの管理へ移動します。
  3. 「Windows 更新にドライバーを含めない」を探します。
  4. 「有効」 → OK にします。
  5. 再起動します。

方法 2：システム設定

  1. Win + R を押し、sysdm.cpl と入力して Enter。
  2. 「ハードウェア」タブ → 「デバイスのインストール設定」。
  3. 「いいえ（デバイスが正常に動作しない可能性があります）」を選択します。
  4. 保存します。

修正が成功したか確認する方法

  1. イベント ビューアー → Windows ログ → システムを開きます。
  2. ソースを GSCx64 に絞り込みます。
  3. 新しいイベントがないこと、またはロールバック前のイベントだけであることを確認します。
  4. ゲームや高負荷アプリを 10～15 分実行します。
  5. 音声のノイズ・途切れや画面のフリーズがなければ、問題は解消されたと判断できます。

FAQ

ドライバー 31.0.101.5590 が一覧に表示されません。
  • 正しいバージョンをダウンロードしたことを確認してください。
  • 「ドライバーの更新」→「コンピューターを参照」→「一覧から選択」→「ディスク使用」を選択し、ドライバーフォルダーを指定してください。
ロールバック後もスタッターが解消されません。
  • 温度、電源、RAM など、別の要因が原因である可能性があります。
  • 一時的な回避策として、デバイス マネージャーで GSC デバイスを無効にしてみてください。
GSC を無効にしても安全ですか？

GSC は GPU ファームウェアの更新や一部のセキュリティ関連処理を担当します。無効にするとスタッターが解消される一方、ファームウェアの更新ができなくなります。

Windows 11 24H2 はなぜ GSC を更新するのですか？

原文では、Windows 11 24H2 が GSC を含むすべてのドライバーを強制的に更新し、グループ ポリシーによってこれを防止できると説明されています。

注記

Windows の大型アップデート後、GSC ドライバーが再び置き換えられる場合があります。その場合は手順 6を繰り返してロールバックしてください。Windows は古いドライバーファイルをディスク上に保持します。

GSC Driver Stutter Fix — NUC X15

Эта инструкция решает проблему с прерыванием звука и фризами изображения, вызванную драйвером Graphics System Controller Firmware Interface (GSC). Проверено на LAPAC71H/LAPAC71G с Arc A730M и Arc A550M.

LAPAC71HLAPAC71GArc A730MArc A550M

Предупреждение

Следующие шаги не обязательны, но рекомендуются для безопасности:

  • Резервная копия: Сохрани важные данные.
  • BitLocker: Если включён, найди ключ восстановления.
  • Интернет: Отключи интернет на время работы.
  • Пароль: Помни пароль от учётной записи (не PIN).
Быстрый способ (рекомендуется): можно пропустить Шаг 1, Шаг 3 и Шаг 7 (скачивание DDU, очистку через DDU и запрет на обновление драйвера). Выполни только Шаги 2, 4, 5, 6 — установи старый драйвер как обычно, а потом откати только устройство GSC. Полный способ (с DDU) используй только если быстрый не помог.

Шаг 1: Скачай DDU (Display Driver Uninstaller)

Быстрый способ: пропусти этот шаг.

  1. Открой https://www.wagnardsoft.com.
  2. Скачай Portable / Self-Extracting версию.
  3. Распакуй архив.

Шаг 2: Скачай драйвер 31.0.101.5590

  1. Открой https://www.comss.ru/download/page.php?id=13872.
  2. Скачай Intel-Graphics-Driver-31.0.101.5590.exe (~866 МБ).
  3. Пока не устанавливай.

Шаг 3: Удали старые драйверы через DDU

Быстрый способ: пропусти этот шаг.

  1. Отключи интернет.
  2. Запусти DDU.exe.
  3. Выбери:
    • Device type: GPU
    • Select device: Intel
  4. Нажми Clean and restart.
  5. ПК перезагрузится в безопасном режиме.
  6. Не подключай интернет, пока не установишь новый драйвер.

Шаг 4: Установи драйвер 31.0.101.5590

  1. Запусти скачанный установщик.
  2. Следуй инструкциям.
  3. Выбери Clean Install, если предложат.
  4. Перезагрузи ПК.
✓ Проверка: Диспетчер устройств → «Системные устройства» → «Intel(R) Graphics System Controller Firmware Interface». Версия — 31.0.101.5590.

Шаг 5: Обнови драйверы видеокарты до актуальной версии

  1. Подключи интернет.
  2. Установи последнюю версию: Intel Arc Graphics Windows Driver.
  3. Перезагрузи.

Шаг 6: Замени драйвер для GSC на старый

  1. Открой Диспетчер устройств.
  2. Разверни «Системные устройства».
  3. Найди «Intel(R) Graphics System Controller Firmware Interface».
  4. ПКМ → «Обновить драйвер».
  5. «Найти драйверы на этом компьютере».
  6. «Выбрать драйвер из списка доступных».
  7. Выбери версию 31.0.101.5590.
  8. «Далее» и дождись установки.
  9. Перезагрузи (опционально).
✓ Проверка: Просмотр событий → Журналы Windows → Система. Фильтр по GSCx64. Событий быть не должно.

Шаг 7: Запрети Windows обновлять GSC

Быстрый способ: пропусти этот шаг.

Способ 1: Групповая политика (рекомендуется)

  1. Win + R → gpedit.msc → Enter.
  2. Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Windows Update → Управление предложениями обновлений Windows.
  3. Найди «Не включать драйверы в обновления Windows».
  4. Включено → OK.
  5. Перезагрузи.

Способ 2: Параметры системы

  1. Win + R → sysdm.cpl → Enter.
  2. Вкладка «Оборудование» → «Параметры установки устройств».
  3. «Нет».
  4. Сохрани.

Как проверить, что проблема решена

  1. Просмотр событий → Журналы Windows → Система.
  2. Фильтр по GSCx64.
  3. Событий нет.
  4. Запусти игру на 10–15 минут.

Частые вопросы

Драйвер 31.0.101.5590 не отображается в списке?
  • Убедись, что скачал правильную версию.
  • Попробуй: «Обновить драйвер» → «Найти на этом компьютере» → «Выбрать из списка» → «Установить с диска» → укажи папку.
Статтеры не исчезли?
  • Возможны другие причины (нагрев, питание, RAM).
  • Попробуй отключить устройство GSC в Диспетчере устройств (временно).
Безопасно ли отключать GSC?

GSC отвечает за прошивку и безопасность. Отключение убирает статтеры, но блокирует обновление прошивки.

Почему Windows 11 24H2 обновляет GSC?

Windows 11 24H2 принудительно обновляет все драйверы. Блокировка через групповую политику предотвращает это.

Примечание

После крупного обновления Windows драйвер GSC может снова обновиться. Повтори Шаг 6. Windows сохраняет старые файлы драйверов.
