FEATURES

控制你的 NUC X15

从系统监控到 EC 控制，将常用的硬件控制功能集中到一个简洁的桌面应用中。

◈

风扇控制

自定义 CPU / GPU 温度对应的风扇转速， 创建自己的 Fan Curve，并支持自动控制。

Temperature → Fan RPM
⚡

功耗控制

对支持的 NUC X15 机型进行处理器和 GPU 功耗参数控制。

CPU PL1 / PL2 / PL4
◌

实时监控

查看 CPU、GPU 温度以及风扇转速等硬件运行状态。

CPU · GPU · FAN
◆

Keyboard LED

Performance Profile

Tray · Startup

硬件控制风险

NUCtool 会与设备底层硬件接口进行交互。 不正确的功耗、温度或风扇配置可能导致系统不稳定、 过热、死机或硬件损坏。

使用前请确认你的设备型号以及相关参数。 对硬件造成的损坏及数据损失，请使用者自行承担风险。
