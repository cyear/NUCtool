PLATFORMS

平台与运行要求

Windows 桌面端提供完整的 NUCtool 控制界面；Linux 目前提供独立工具，功能范围与 Windows 应用不同。

▣

Windows 桌面应用

README 标注支持 Windows 11。依赖 UniwillService、UWACPIDriver 与 WebView2；Windows 10 1803 及更新版本通常已包含 WebView2。硬件控制能力仍取决于机型与固件。

Windows 11 · Tauri 2
⌘

Linux 独立工具

仓库另提供 Linux 风扇控制工具；Linux 音效 Beta 面向 Arch Linux x86_64、PipeWire/WirePlumber、48 kHz 双声道和 SoundEdge Music mode-0。它们不是 Windows 桌面应用的完整 Linux 移植。

Linux utilities · limited scope
⚙

设备与固件差异

低层操作依赖 EC、BIOS、驱动及设备硬件。BIOS NVRAM 写入、功耗和风扇设置可能影响启动与稳定性；操作前请阅读项目说明并备份重要数据。

硬件控制风险

NUCtool 会与设备底层硬件接口进行交互。 不正确的功耗、温度或风扇配置可能导致系统不稳定、 过热、死机或硬件损坏。

使用前请确认你的设备型号以及相关参数。 对硬件造成的损坏及数据损失，请使用者自行承担风险。
