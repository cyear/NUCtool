> [!NOTE]
>
> Инструмент для ноутбуков серии Intel NUC X15, включая LAPAC71H, LAPKC71F и другие совместимые модели. Поддерживает управление энергопотреблением, переключение режимов, настройку кривой вентиляторов (Fan Control), параметры дисплея, управление светодиодной подсветкой клавиатуры и другие функции.
>
> Поддерживается отображение в реальном времени температуры CPU и GPU, APC_WATT, скорости вращения вентиляторов Main и Secondary, поддержка сочетаний клавиш FN, переключение режимов, ограничение энергопотребления (поддерживаются: CPU: PL1/PL2/PL4, GPU: PL1/PL2, PSYS PL1, максимальный уровень заряда Battery), переключение режимов дисплея, настройка подсветки клавиатуры и другие функции.

## 1. Характер рисков

Данное программное обеспечение предназначено для аппаратного мониторинга ноутбуков Intel NUC, разблокировки и настройки ограничений энергопотребления (PL1/PL2), управления скоростью вращения вентиляторов и выполнения операций на низком уровне.

Подобные операции **напрямую взаимодействуют с прошивкой оборудования (BIOS/EC) и системными компонентами**, что принципиально отличается от работы обычных приложений.

## Порядок использования конфигурации BIOS

1. Считать BIOS
2. Экспортировать NVRAM
3. Записать BIOS

- Необходимо установить пароль администратора в настройках BIOS (пользовательский пароль можно пропустить)
- Считывание может вызвать подтормаживание устройства и другие проблемы; при записи необходимо дождаться результата во всплывающем окне (запись занимает некоторое время); вступило ли в силу — проверяйте самостоятельно
- Уточнение: экспортируйте после внесения изменений во все параметры; теоретически все изменения будут сохранены; пояснения под предпросмотром могут быть неточными

## Дополнительная информация

- `Fn + 1` => режим производительности
- `Fn + 2` => сбалансированный режим
- `Fn + 3` => энергосберегающий режим
- `Fn + 4` => режим бенчмарка
- `--hide` => запуск приложения только в системном трее
- `--fan-control` => автоматический запуск управления вентиляторами
- `--no-osd` => отключение OSD
- `--log` => включение журналирования
- Расположение программы по умолчанию: `C:\Program Files\NUCtool\`
- Расположение файла конфигурации и журналов по умолчанию: `%AppData%\com.cyear.nuctool`
- Для использования в Linux рекомендуется ознакомиться с драйвером Linux, указанным в разделе благодарностей в нижней части документа.

## Управление вентиляторами в Linux

```bash
# 1. Скачайте nuctool-fan-linux.tar.xz

# 2. Установите acpi_call
sudo pacman -S acpi_call
# или
sudo pacman -S acpi_call-dkms

# 3. Загрузите
sudo modprobe acpi_call

# 4. Запустите

sudo ./nuctool-fan --fan

# Параметры:
#   --fan              Инициализировать и применить кривую вентиляторов из fan.json
#   --stop             Отключить пользовательское управление вентиляторами
#   --read <адрес>     Прочитать 1 байт данных по указанному адресу EC
#   --write <адрес> <значение> Записать 1 байт данных по указанному адресу EC
#   --ui               Открыть терминальный редактор кривой вентиляторов
#   --help             Показать справку



```

## Как сообщить об ошибке и запросить новую функцию

### 1. Ошибка

1. Запустите NUCtool с параметром `--log` из командной строки администратора
2. Предоставьте скриншоты или видео
3. Предоставьте `%AppData%\com.cyear.nuctool\crash_*.log` (если есть) и `%AppData%\com.cyear.nuctool\NUCtool.log`
