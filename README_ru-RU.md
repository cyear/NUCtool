> [!NOTE]
>
> Инструмент для ноутбуков серии Intel NUC X15, включая LAPAC71H, LAPKC71F и другие совместимые модели. Поддерживает управление энергопотреблением, переключение режимов, настройку кривой вентиляторов (Fan Control), параметры дисплея, управление светодиодной подсветкой клавиатуры и другие функции.
>
> Поддерживается отображение в реальном времени температуры CPU и GPU, APC_WATT, скорости вращения вентиляторов Main и Secondary, поддержка сочетаний клавиш FN, переключение режимов, ограничение энергопотребления (поддерживаются: CPU: PL1/PL2/PL4, GPU: PL1/PL2, PSYS PL1, максимальный уровень заряда Battery), переключение режимов дисплея, настройка подсветки клавиатуры и другие функции.

## 1. Характер рисков

Данное программное обеспечение предназначено для аппаратного мониторинга ноутбуков Intel NUC, разблокировки и настройки ограничений энергопотребления (PL1/PL2), управления скоростью вращения вентиляторов и выполнения операций на низком уровне.

Подобные операции **напрямую взаимодействуют с прошивкой оборудования (BIOS/EC) и системными компонентами**, что принципиально отличается от работы обычных приложений.

## 2. Риски для оборудования и данных

Вы прямо подтверждаете, что понимаете и добровольно принимаете следующие потенциальные риски:

- **Физическое повреждение:** неправильная настройка энергопотребления или стратегия остановки вентиляторов может привести к **перегреву, повреждению или сокращению срока службы CPU, подсистемы питания материнской платы (VRM) и других компонентов**.

- **Стабильность системы:** неправильные настройки могут привести к **частым синим экранам, зависаниям, невозможности загрузки системы (Brick)** или повреждению данных на накопителе (SSD).

- **Потеря гарантии:** использование данного программного обеспечения для изменения параметров устройства **может привести к потере официальной гарантии производителя**. Конкретные условия зависят от политики соответствующего производителя.

## Дополнительная информация

- `Fn + 1` => режим производительности
- `Fn + 2` => сбалансированный режим
- `Fn + 3` => энергосберегающий режим
- `Fn + 4` => режим бенчмарка
- `--hide` => запуск приложения только в системном трее
- `--fan-control` => автоматический запуск управления вентиляторами
- `--no-osd` => отключение OSD
- Расположение программы по умолчанию: `C:\Program Files\NUCtool\`
- Расположение файла конфигурации по умолчанию: `%AppData%\com.cyear.nuctool`
- Для использования в Linux рекомендуется ознакомиться с драйвером Linux, указанным в разделе благодарностей в нижней части документа.
